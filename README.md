# 🎬 Movie Ticket Booking System

A desktop-based **Movie Ticket Booking System** developed using **Java Swing** and **AWT** as part of the **Advanced Java Mini Project (6th Semester)**.

The application provides an interactive graphical interface for booking movie tickets, calculating ticket prices, applying discounts for bulk bookings, and managing booking records during the application session.

---

## ✨ Features

- 🎟️ Book movie tickets through a GUI
- 👤 Customer name input
- 🎬 Movie selection using ComboBox
- 💺 Seat selection (Normal / VIP)
- 💰 Automatic ticket price calculation
- 🎁 10% discount on bookings above 5 tickets
- 🆔 Random Booking ID generation
- 📅 Automatic Date & Time generation
- ✅ Input validation with error messages
- 📄 Booking confirmation display
- 📋 View all bookings
- 🧹 Clear booking form
- 🎨 Modern Java Swing interface

## ⚙️ How It Works

1. Enter the customer name.
2. Select a movie.
3. Enter the number of tickets.
4. Choose the seat type.
5. Click **Book**.
6. The application validates the input.
7. Ticket price is calculated automatically.
8. Discount is applied for bulk bookings.
9. Booking details are displayed.
10. Click **View** to see all bookings.
11. Click **Clear** to reset the form.

## ▶️ How to Run

1. Clone this repository.

```bash
git clone https://github.com/Rakshaa17/Movie-Ticket-Booking-System.git
```

2. Open the project in your preferred Java IDE (VS Code, IntelliJ IDEA, Eclipse, etc.).

3. Compile the Java file.

```bash
javac MovieBookingSystem.java
```

4. Run the application.

```bash
java MovieBookingSystem
```
